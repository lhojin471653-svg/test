오늘 할 일 v1.2.0 · 서연 개인스킨 시안 정밀화

주요 변경
- 시안과 같은 상단 헤더 / 왼쪽 메뉴 / 중앙 할 일+달력+메모 / 오른쪽 대형 사진 구조
- 서연 스킨 오른쪽 사진 폭 확대
- 왼쪽 하단: "오빠 사랑해~ / 나랑 놀자~ ♡"
- 서연 전용 문구는 Windows에 설치된 손글씨 계열 글꼴을 자동 탐색
- 설정 > 서연 문구 글꼴에서 설치된 후보 글꼴 선택 가능
- 설정 > 서연 스킨 사진에서 JPG/PNG/WEBP 사진 변경 및 기본 사진 복원
- 사진은 비율을 유지한 채 패널에 맞춰 자동 크롭
- 기존 일정/알림/달력/메모/통계 기능 유지

주의
- 글꼴 파일은 프로그램에 포함하지 않습니다. PC에 설치된 글꼴을 사용합니다.
- 손글씨 폰트가 없으면 가독성 좋은 기본 한글 폰트로 자동 대체됩니다.
